# Ring Call — Coach Class Tools

Projector-first tools for a **live boxing class**. The class works with their hands; the coach runs the room from a TV, tablet, or laptop.

## What it is

1. **Run a Class** — Guided session templates (warm-up → technique → pads → finisher)
2. **Pad Caller** — Giant combo board that auto-calls while you hold mitts
3. **Drill Board** — Fullscreen physical drills (shadow / partner / conditioning)
4. **Team Battle** — Red vs Blue scoring for energy and competition

Students do **not** tap phones. Space / Enter advances from the coach device.

## Run

```bash
cd boxing-games
npm install
npm run dev
```

Cast the browser to the gym screen. Keep the laptop/tablet as your remote.
