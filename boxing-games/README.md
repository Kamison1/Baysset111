# Ring Call — Boxing Class Games

Interactive training games for boxing coaches. Open on a phone, tablet, or project onto a gym screen.

## Games

1. **Flash Combos** — Memorize punch sequences and throw them back (Simon Says for boxing). Keys `1–4`.
2. **Pad Panic** — Reaction lights; hit the lit pad before it fades. Keys `1–6`.
3. **Coach Caller** — Full-class combo display with throw countdown. Space / Enter = next combo.
4. **Round Roulette** — Work/rest timer that spins a random drill each round.
5. **Class Scoreboard** — Track fighter points on-device for challenges.

## Run locally

```bash
cd boxing-games
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Class tips

- **Warm-up:** Pad Panic (easy, 4 pads)
- **Skill focus:** Flash Combos or Coach Caller on the big screen
- **Conditioning block:** Round Roulette (60s / 30s × 6)
- **Competition finish:** Scoreboard + Pad Panic high scores
